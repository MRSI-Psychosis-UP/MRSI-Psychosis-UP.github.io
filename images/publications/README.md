# Publication thumbnails

All five publications use the supplied images below. The connectome paper
shares the existing `images/general/mrsi_connectome.png` figure with the homepage.
The paths below are relative to the site root. Replace an image at the same path
to update its thumbnail without changing the HTML.

| --- | --- |

| `images/publications/WhiteMatterDisruptionsinSchizophrenia.jpeg` | White Matter Disruptions in Schizophrenia Are Spatially Widespread and Topologically Converge on Brain Network Hubs. |

Square images of at least 220 × 220 pixels work well. Figures keep their original
proportions and fit inside the reserved thumbnail area without being cropped.
Until an image is available, its area displays “Figure coming soon”. After adding
an image, reload the page to see it. Commit and push the image files with the site
to make them available on GitHub Pages.
